# FORMAL · אתר תדמית לגרפיקאית ומפיקה

אתר סטטי, מהיר וקולנועי: שחור · אדום · לבן, רקע עשן וערפל ב-WebGL, פתיח "אחד · שתיים · שלוש · אקשן", גלריית עבודות עם נגן מובנה (בלי אפשרות הורדה), דף אודות ודף המלצות לקוחות.

## מבנה הפרויקט

| קובץ / תיקייה | מה יש שם |
|---|---|
| `index.html` | דף הבית (פתיח, עבודות נבחרות, שירותים, ציטוט, צור קשר) |
| `works.html` | כל העבודות + סינון לפי קטגוריה |
| `about.html` | אודות (טקסט, תמונה, תהליך עבודה, כלים) |
| `clients.html` | המלצות לקוחות + גלילת קרדיטים |
| `add.html` | **כלי עזר** ליצירת פריט חדש (לא מופיע בתפריט) |
| `publish.sh` | העלאה לגיטהאב ולאוויר בפקודה אחת |
| `assets/img/logo.png` · `logo-icon.png` | הלוגו (שקוף לכותרת ולפוטר) והאייקון לדפדפן |
| `content/site.js` | שם, תפקיד, פרטי קשר, רשימת לקוחות, שמות קטגוריות |
| `content/works.js` | **העבודות** (סרטונים ותמונות) |

| `assets/js/fog.js` · `hero.js` · `main.js` | מנוע הערפל, הפתיח, והלוגיקה של האתר |

## איך מוסיפים סרטון (3 דקות)

### דרך מומלצת: YouTube
1. מעלים את הסרטון ליוטיוב. ב-**Visibility** בוחרים **Unlisted (לא רשום)**: הסרטון לא יופיע בחיפוש, רק מי שבאתר יראה אותו.
2. מעתיקים את הקישור (למשל `https://youtu.be/XXXXXXXXXXX`).
3. נכנסים ל-`add.html` באתר (למשל `https://<שם-המשתמש>.github.io/formal/add.html`), ממלאים את הטופס, לוחצים **העתקה**.
4. בגיטהאב פותחים את `content/works.js` → לוחצים על העיפרון ✎ → מדביקים את הקוד **אחרי הסוגר `}` של הפריט האחרון, לפני `];`** → **Commit changes**.
5. תוך כדקה הסרטון באתר.

> הנגן המוטמע של יוטיוב לא מציג כפתור הורדה. ה-embed הוא דרך `youtube-nocookie.com`, בלי המלצות לסרטונים אחרים.

### Google Drive
1. מעלים את הסרטון לדרייב. קליק ימני → **שיתוף** → "כל מי שיש לו את הקישור" → **צופה**.
2. באותו חלון לוחצים על ⚙ (הגדרות) ו**מבטלים** את "צופים יכולים להוריד, להדפיס ולהעתיק". זה מה שמונע הורדה.
3. מעתיקים את הקישור ומדביקים ב-`add.html` כמו עם יוטיוב.

### Jumbo Mail
ג'מבו מייל הוא שירות להעברת קבצים, לא לאחסון. הקישורים שלו **פגים אחרי כמה ימים** ואי אפשר להטמיע אותם באתר. השתמשי בו כדי לשלוח לעצמך קבצים, ואז העלי אותם ליוטיוב או לדרייב.

### קובץ וידאו ישירות באתר
אפשר להעלות `mp4` לתיקייה `assets/media` (בגיטהאב: **Add file → Upload files**) ולכתוב `src: "assets/media/שם-הקובץ.mp4"`. מתאים לסרטונים קצרים (עד ~25MB לקובץ). לסרטונים ארוכים עדיף יוטיוב.

## איך מוסיפים תמונה
1. מעלים את התמונה ל-`assets/media` בגיטהאב (**Add file → Upload files**). מומלץ JPG/WebP ברוחב 1600–2000px.
2. ב-`add.html` בוחרים סוג **תמונה**, כותבים בנתיב `assets/media/שם-הקובץ.jpg`, ומעתיקים את הקוד ל-`content/works.js`.

התמונות באתר מוגנות: אין גרירה, אין קליק ימני, אין שמירה בלחיצה ארוכה בנייד.

## המלצות לקוחות
עורכים את `content/testimonials.js` (או משתמשים בטאב **המלצת לקוח** ב-`add.html`). אפשר לצרף תמונה, ואפשר **המלצת וידאו**: שדה `video` עם קישור יוטיוב/דרייב – תופיע עם כפתור הפעלה ותתנגן באתר.

## טקסטים ופרטי קשר
- **שם, תפקיד, טלפון, וואטסאפ, מייל, אינסטגרם, רשימת לקוחות**: `content/site.js`
- **טקסט האודות, סטטיסטיקות, תהליך, כלים**: ישירות ב-`about.html` (הטקסט בתוך `<p> ... </p>`)
- **תמונה שלך לאודות**: החליפי את `assets/img/portrait.svg` (או שני את הנתיב ב-`about.html`)
- **טקסטים בדף הבית** (שירותים, כותרות): ב-`index.html`

טופס יצירת הקשר פותח הודעת וואטסאפ מוכנה למספר שב-`site.js` (שדה `whatsapp`, פורמט `972501234567`). אין צורך בשרת.

## הגנה על התוכן
- וידאו: נגן יוטיוב/דרייב מוטמע ללא כפתור הורדה; קבצים מקומיים עם `controlsList="nodownload"`, בלי Picture-in-Picture, בלי תפריט קליק ימני.
- תמונות: שכבת מגן מעל התמונה, ביטול גרירה, קליק ימני ובחירה.
- ⚠ אף אתר לא יכול למנוע הקלטת מסך. מה שכן: אין באתר שום כפתור או דרך פשוטה להוריד.

## תצוגה מקומית
אפשר פשוט לפתוח את `index.html` בדפדפן בלחיצה כפולה. התוכן נטען מקבצי `content/*.js`, כך שהכול עובד גם בלי שרת.

## העלאה לאוויר (GitHub Pages)

**הדרך הקצרה (WSL / Linux):** בטרמינל, בתוך תיקיית הפרויקט:

```bash
bash publish.sh
```

הסקריפט מתחבר לגיטהאב (מודפס קוד חד-פעמי שמאשרים בדפדפן), יוצר את הריפו `formal`, דוחף את הקוד, מפעיל GitHub Pages ומדפיס את הקישורים. אפשר להריץ אותו שוב אחרי כל שינוי כדי לעדכן את האתר.

**הדרך הידנית:**
האתר מתארח בחינם ב-GitHub Pages:

1. **Settings → Pages** בריפו → **Source: Deploy from a branch** → **Branch: main / (root)** → Save.
2. הכתובת: `https://<שם-המשתמש>.github.io/formal/`
3. כל שינוי שעושים בקבצים ומאשרים ב-Commit עולה לאוויר תוך כדקה.

### דומיין משלך (אופציונלי)
כשתרצי דומיין כמו `formal.co.il`: קונים דומיין, ב-**Settings → Pages → Custom domain** כותבים אותו, ואצל ספק הדומיין מוסיפים רשומת `CNAME` שמצביעה ל-`<שם-המשתמש>.github.io`. GitHub מנפיק HTTPS אוטומטית.
