# FORMAL · אתר תדמית לגרפיקאית ומפיקה

אתר סטטי, מהיר וקולנועי: שחור · אדום · לבן, רקע עשן וערפל ב-WebGL, פתיח "אחד · שתיים · שלוש · אקשן", גלריית עבודות עם נגן מובנה (בלי אפשרות הורדה), דף אודות, דף המלצות, טופס יצירת קשר שמגיע למייל של בעלת האתר בלבד, עמוד מדיניות פרטיות, ו**ממשק ניהול** עם כניסה במייל וסיסמה.

- **האתר:** https://chana-c.github.io/formal/
- **ממשק הניהול:** https://chana-c.github.io/formal/admin.html
- **הקוד:** https://github.com/Chana-C/formal

## איך מעלים תוכן

נכנסים לממשק הניהול עם המייל והסיסמה. כל שמירה שם נכתבת ישירות לאתר ומתפרסמת תוך כדקה. בלשונית **"איך מעלים?"** בתוך הממשק יש את ההוראות האלה.

### 🎬 סרטון דרך YouTube (מומלץ)
1. מעלים את הסרטון ליוטיוב (studio.youtube.com → Create → Upload).
2. ב-**Visibility** בוחרים **Unlisted / לא רשום**: הסרטון לא יופיע בחיפוש, רק מי שבאתר יראה אותו.
3. מעתיקים את הקישור של הסרטון.
4. בממשק: **עבודות → + עבודה חדשה** → מדביקים את הקישור → ממלאים שם ולקוח → **שמירה ופרסום**.

הנגן באתר הוא נגן יוטיוב בלי כפתור הורדה ובלי המלצות לסרטונים אחרים (youtube-nocookie). התמונה המקדימה נלקחת אוטומטית, ואפשר להחליף אותה.

### 📁 סרטון דרך Google Drive
1. מעלים את הקובץ לדרייב.
2. קליק ימני → **שיתוף** → "כל מי שיש לו את הקישור" → **צופה**.
3. באותו חלון לוחצים ⚙ ו**מבטלים** את "צופים יכולים להוריד, להדפיס ולהעתיק". **בלי השלב הזה אפשר יהיה להוריד.**
4. מעתיקים קישור → בממשק: **עבודות → + עבודה חדשה** → מדביקים → שמירה.

### 🖼 תמונות (וסרטונים קצרים) ישירות לאתר
1. בממשק: **תמונות וקבצים → + העלאת קבצים** (אפשר כמה בבת אחת, עד 20MB לקובץ).
2. **עבודות → + עבודה חדשה** → סוג "תמונה" (או "קובץ וידאו") → **בחירה מהקבצים**.

**האם זה מכביד על האתר?** תמונות: לא. הן מוגשות מרשת ההפצה (CDN) של GitHub, וזה מתאים למאות תמונות. מומלץ JPG או WebP ברוחב 1600–2000 פיקסלים (בדרך כלל 200–600KB לתמונה). סרטונים: מתאים רק לקליפים קצרים (עד ~20MB). סרטון ארוך מכביד על הגולש (הקובץ כולו נטען, בלי התאמת איכות) ועל הריפו (המכסה הכוללת היא ~1GB, וקבצים שנמחקו נשארים בהיסטוריה). לכן סרטונים מלאים תמיד דרך יוטיוב או דרייב, שמזרימים אותם באיכות מותאמת ובלי לגעת באתר.

### 📨 Jumbo Mail
ג'מבו מייל הוא שירות **להעברת** קבצים, לא לאחסון: הקישורים פגים אחרי כמה ימים, לא ניתנים להטמעה, והם תמיד קישורי הורדה. לכן אי אפשר להציג דרכו תוכן באתר. הדרך: מקבלים את הקובץ בג'מבו מייל → מורידים למחשב (לחיצה אחת) → מעלים ליוטיוב / דרייב / לממשק (תמונות וקבצים). שתי לחיצות.

### קישור "לצפייה ביוטיוב / בדרייב" מתחת לסרטון?
קיים ככפתור כבוי ב-**הגדרות האתר → נגן**. ההמלצה: להשאיר כבוי. הקישור מוציא את הצופים מהאתר, ובדרייב עלול לאפשר הורדה אם הגדרות השיתוף לא הוגבלו.

## ממשק הניהול

| לשונית | מה עושים שם |
|---|---|
| עבודות | הוספה, עריכה, מחיקה, סידור בגרירה, ★ לדף הבית (עד 4) |
| המלצות | ציטוטים, תמונה, המלצת וידאו, ★ לדף הבית |
| תמונות וקבצים | העלאה, העתקת נתיב, מחיקה |
| הגדרות האתר | שם, תפקיד, טלפון, מייל, לקוחות, קטגוריות |
| מנהלים | בעלת האתר מוסיפה/מסירה מנהלים לפי מייל וקובעת סיסמה ראשונית; כל אחד משנה את הסיסמה שלו. מנהלים יכולים להעלות ולערוך תוכן, אבל לא לנהל מנהלים או לראות פניות |
| פניות | (בעלת האתר בלבד) ההודעות שהגיעו מטופס יצירת הקשר, עם קישורי טלפון/מייל ומחיקה |
| איך מעלים? | ההוראות שלמעלה, בתוך הממשק |

- שדה המייל בכניסה מציע השלמה של סיומות נפוצות (gmail.com, walla.co.il וכו').
- בדפדפן שבו נכנסת פעם לממשק, מופיע בתחתית האתר כפתור קטן "ניהול". מבקרים אחרים לא רואים אותו. בכל מקרה הכניסה תמיד דרך `/admin.html`.
- הנקודה בסרגל העליון מראה את מצב הפרסום: אדומה מהבהבת = האתר נבנה, לבנה = פורסם.

**אבטחה:** הסיסמאות נשמרות מוצפנות (PBKDF2); 10 ניסיונות כושלים חוסמים ל-15 דקות; ההתחברות תקפה 7 ימים; כל קומיט מסומן בשם בעלת האתר ובמייל של מי ששמר.

### שכחתי סיסמה
- **דרך המייל:** במסך הכניסה לוחצים "שכחתי סיסמה", מזינים את המייל, וקישור לאיפוס (תקף 30 דקות) נשלח **למייל של בעלת האתר** (הכתובת שחיברת ל-Web3Forms). אם מנהל/ת אחר/ת ביקש/ה איפוס, בעלת האתר מקבלת את הקישור ומעבירה לו/לה. דורש שמפתח Web3Forms הוגדר (ראי "פניות מהאתר").
- **מהטרמינל (בלי מייל):** באובונטו, `bash admin-api/reset-password.sh` לאתר החי, או `bash admin-api/reset-password.sh --local` לתצוגה המקומית. מבקש מייל וסיסמה חדשה.
- **בתצוגה המקומית** אין צורך במייל: "שכחתי סיסמה" מציג את קישור האיפוס ישירות על המסך.

## פניות מהאתר (טופס יצירת קשר)

הטופס בדף הבית שולח את ההודעה לשרת הניהול, והוא:
1. **שולח אותה למייל שלך** (דרך Web3Forms, חינם עד 250 פניות בחודש), אם הוגדר מפתח.
2. **שומר גיבוי** בלשונית "פניות" בממשק, שרואה רק בעלת האתר, ל-180 יום.

הפניות לא מופיעות בשום מקום באתר ואף מנהל אחר לא רואה אותן. הגנות: שדה מלכודת לבוטים, הגבלה של 5 פניות לשעה מאותו מקור, ואישור חובה של מדיניות הפרטיות.

**הפעלת השליחה למייל (פעם אחת):** נכנסים ל-https://web3forms.com, מזינים את המייל שאליו תרצי לקבל פניות, לוחצים על הקישור במייל שמתקבל ומעתיקים את ה-**Access Key**. ואז מריצים שוב `bash admin-api/deploy-admin.sh` ומדביקים את המפתח כשהוא מתבקש.

## מדיניות פרטיות ותנאי שימוש

`privacy.html` מכיל מדיניות פרטיות (לפי חוק הגנת הפרטיות התשמ"א-1981) ותנאי שימוש (זכויות יוצרים, איסור הורדה והעתקה, הגבלת אחריות). קישור אליו בתחתית כל עמוד, ובטופס יצירת הקשר יש תיבת אישור חובה. **זהו נוסח כללי ולא ייעוץ משפטי**; מומלץ שעורך/ת דין יעבור עליו אם האתר יאסוף מידע מעבר לטופס יצירת קשר. השם והמייל בעמוד נלקחים אוטומטית מהגדרות האתר.

## הפעלת ממשק הניהול (פעם אחת)

ממשק הניהול צריך שרת קטן. הוא רץ בחינם ב-Cloudflare Workers.

1. פותחים חשבון חינמי ב-https://dash.cloudflare.com/sign-up ומאמתים את המייל.
2. בטרמינל של WSL, מתוך תיקיית הפרויקט:

```bash
cd ~/formal && bash admin-api/deploy-admin.sh
```

הסקריפט: מתחבר ל-Cloudflare (נפתח דפדפן לאישור), יוצר את מאגר המנהלים, מפרסם את השרת, מבקש טוקן גיטהאב (Enter = החיבור הקיים), את המייל והסיסמה הראשונית שלך, מפתח Web3Forms (אופציונלי), ורושם את כתובת השרת באתר. להרצה חוזרת (עדכון קוד השרת או הוספת מפתח): אותה פקודה. סודות שכבר הוגדרו נשמרים.

## תצוגה מקומית (גם כשהרשת חוסמת github.io / workers.dev)

```bash
cd ~/formal && bash preview-admin.sh
```

- האתר: http://localhost:8080/ · ממשק הניהול: http://localhost:8080/admin.html
- בפעם הראשונה הסקריפט שואל מייל וסיסמה לכניסה המקומית (נשמרים רק במחשב הזה).
- **השמירות מהממשק המקומי נכתבות לגיטהאב האמיתי**, כלומר האתר החי מתעדכן.
- רשימת המנהלים והפניות של הממשק המקומי נפרדות מאלה של הממשק החי.
- לסגירה: Ctrl+C בטרמינל.

לחיצה כפולה על index.html לא תציג עבודות, כי הדפים טוענים את התוכן מקבצי JSON דרך שרת.

## עדכוני קוד (לא תוכן)
עריכת קבצים בתיקייה `~/formal` ואז:

```bash
bash publish.sh
```

## דומיין משלך (אופציונלי)
ב-GitHub: **Settings → Pages → Custom domain**, ואצל ספק הדומיין רשומת `CNAME` ל-`chana-c.github.io`. HTTPS אוטומטי. אחרי זה מוסיפים את הדומיין החדש ל-`ALLOWED_ORIGINS` ב-`admin-api/wrangler.toml` ומריצים שוב את `deploy-admin.sh`.
