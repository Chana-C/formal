איך מעלים תוכן?

שלוש דרכים, לפי סוג הקובץ.

🎬 סרטון דרך YouTube מומלץ

  1. מעלים את הסרטון ליוטיוב (studio.youtube.com → Create → Upload).
  2. ב-Visibility בוחרים Unlisted / לא רשום. הסרטון לא יופיע בחיפוש, רק באתר.
  3. מעתיקים את הקישור של הסרטון.
  4. כאן: עבודות → + עבודה חדשה → מדביקים את הקישור → שמירה.

הנגן באתר הוא נגן יוטיוב בלי כפתור הורדה ובלי המלצות. התמונה המקדימה נלקחת אוטומטית.

📁 סרטון דרך Google Drive

  1. מעלים את הקובץ לדרייב.
  2. קליק ימני → שיתוף → "כל מי שיש לו את הקישור" → צופה.
  3. באותו חלון: ⚙ → מבטלים "צופים יכולים להוריד, להדפיס ולהעתיק".
  4. מעתיקים קישור → כאן: עבודות → + עבודה חדשה → מדביקים → שמירה.

בלי שלב 3, מי שימצא את הקישור יוכל להוריד. עם שלב 3, לא.

🖼 תמונות

  1. כאן: תמונות וקבצים → + העלאת קבצים (אפשר כמה בבת אחת).
  2. אחרי ההעלאה לוחצים "העתקת נתיב".
  3. עבודות → + עבודה חדשה → סוג "תמונה" → מדביקים את הנתיב, או לוחצים "בחירה מהקבצים".

מומלץ JPG או WebP ברוחב 1600–2000 פיקסלים. התמונות באתר מוגנות מגרירה, קליק ימני ושמירה.

📨 Jumbo Mail

ג'מבו מייל הוא שירות להעברת קבצים, לא לאחסון: הקישורים פגים אחרי כמה ימים ואי אפשר להטמיע אותם באתר. השתמשי בו רק כדי להעביר קבצים (למשל מהמחשב של העורך אלייך), ואז העלי ליוטיוב, לדרייב, או כאן לתמונות וקבצים.

⏱ מתי זה עולה לאוויר?

כל שמירה נשמרת ישירות באתר (כקומיט בגיטהאב על שמך). האתר מתעדכן תוך כדקה. אפשר לעקוב בנקודה שלמעלה: אדומה = בבנייה, לבנה = פורסם.
